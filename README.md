## 🙋‍♂️ Sobre mim

Com uma base sólida em suporte técnico e resolução de problemas complexos em produção, hoje atuo como Desenvolvedor de Software com foco em criar aplicações eficientes e escaláveis. 

Minha trajetória me deu uma visão privilegiada do ciclo de vida de um sistema: **eu não penso apenas em como escrever o código, mas em como ele vai se comportar, falhar e escalar no mundo real.** Uno o instinto analítico de quem operava bancos de dados e integrações críticas com as melhores práticas do desenvolvimento moderno.

*   🔭 Atualmente desenvolvendo o **Projeto VTX**, uma API multi-tenant para gestão de clientes e assinaturas.
*   🧠 Focado em **Arquitetura Backend, APIs RESTful, Modelagem Relacional** e **Clean Code**.
*   🌐 Expandindo habilidades no Full Stack com **Angular** e **React**.
*   🐳 Aprimorando fluxos de deploy com **Docker / Docker Compose**.
*   🧪 Praticando cultura de qualidade com testes automatizados (**Vitest**).
*   📚 Movido a aprendizado prático: construo projetos reais que resolvem problemas reais.
